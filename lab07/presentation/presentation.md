# Команда `pause`

## Пошаговое появление текста

- файл `presentation-2.tex` демонстрирует работу `\pause`;
- первая строка текста видна сразу;
- последующие строки появляются после паузы.

![Пример работы pause](im4_1.png){ width=55% }

## Пошаговое раскрытие списка

- элементы списка выводятся по одному;
- удобно для постепенного объяснения материала;
- после списка может появляться дополнительный текст.

![Пошаговый список](im4_3.png){ width=55% }

## Паузы в блоках

- использование `\pause` для `block`, `exampleblock`, `alertblock`;
- блоки появляются последовательно;
- `alertblock` подчёркивает наиболее важную информацию.

![Блоки с паузами](im4_5.png){ width=55% }

# Команда `uncover`

## Uncover в формулах

- файл `presentation-3.tex` показывает поэтапное раскрытие производных;
- формулы появляются по одной с помощью `\uncover<...->`;
- удобно для пошагового вывода решения.

![Uncover в формулах](im6_1.png){ width=55% }

## Uncover в списках

- каждый пункт списка видим с определённого шага показа;
- можно добавлять итоговую строку только на последнем кадре;
- обеспечивается гибкий контроль видимости элементов.

![Uncover в списке](im6_3.png){ width=55% }
