# Цель работы

Освоение создания презентаций в классе **beamer**, установка недостающих пакетов в системе TeX Live, анализ возникающих ошибок при компиляции и последующая проверка корректности формирования PDF-файла.

# Ход выполнения

## Проверка компиляции и выявление ошибки

При первой попытке собрать документ возникла ошибка, связанная с отсутствием класса `beamer`.  
LaTeX сообщил о невозможности найти файл `beamer.cls`, что привело к остановке компиляции.

![Ошибка: файл beamer.cls не найден](im1.png){ #fig:001 width=80% }

Это указывает на то, что пакет **beamer** не был установлен в текущей конфигурации TeX Live.

## Установка необходимых пакетов

Для устранения ошибки был установлен пакет *beamer* вместе с зависимостями (`pgf`, `translator`, `xcolor` и др.).  
После завершения установки файловые базы были обновлены, что позволило LaTeX обнаружить требуемый класс.

![Установка пакета beamer](im2.png){ #fig:002 width=80% }

## Проверка успешной установки

После обновления система успешно обнаруживает файл `beamer.cls`, а повторный запуск компиляции подтверждает корректное подключение всех требуемых пакетов.

![Успешное подключение beamer.cls при компиляции](im3.png){ #fig:003 width=80% }

Компиляция завершается с предупреждением о необходимости повторного запуска, что является нормальным для Beamer при наличии внутренних ссылок и структурных элементов.
