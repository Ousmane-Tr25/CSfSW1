# Цель работы

Изучить основы создания таблиц в LaTeX, освоить способы выравнивания столбцов, разобраться в требованиях к структуре строк таблицы, а также получить практические навыки использования команды `multicolumn` для объединения ячеек.

# Ход выполнения

На первом этапе была подготовлена рабочая директория для выполнения задания. В каталоге `latex-exercises` была создана новая папка `chapter-5-tables`, после чего выполнен переход в неё.

После создания файла `exercise-5.14.tex` была выполнена первичная компиляция документа с использованием `pdflatex`. Компилятор успешно обработал исходный файл, подключил стандартный класс `article`, а также необходимые пакеты для работы с таблицами. Ошибок и предупреждений на данном этапе обнаружено не было.

![Первый запуск pdflatex без ошибок](im2.png){ #fig:002 width=80% }

В результате был сформирован PDF-файл, содержащий одну страницу.

В документ была добавлена простая таблица, состоящая из трёх столбцов: *Animal*, *Food* и *Size*. Все столбцы использовали выравнивание по левому краю. Таблица корректно отобразилась в итоговом PDF-документе.

![Простейшая таблица с тремя столбцами](im3.png){ #fig:003 width=80% }

## Повторная компиляция после правок

![Повторная компиляция после редактирования](im4.png){ #fig:004 width=80% }

## Тестирование различных выравниваний столбцов

Далее были проведены эксперименты с различными типами выравнивания столбцов: по левому краю (`l`), по центру (`c`) и по правому краю (`r`). Были протестированы комбинации `l-c-r`, `c-c-c` и `r-l-r`. Все варианты корректно отобразились, при этом визуальное расположение содержимого столбцов изменялось в соответствии с заданным выравниванием.

![Тестирование различных вариантов выравнивания столбцов](im6.png){ #fig:005 width=80% }

## Анализ ошибочных случаев в строках таблицы

Отдельно были рассмотрены ситуации с некорректным количеством элементов в строках таблицы. При недостаточном количестве разделителей `&` LaTeX сообщает об ошибке, так как число элементов не соответствует количеству столбцов. Аналогичная ошибка возникает и при использовании избыточного количества разделителей.

В результате был сделан вывод: для таблицы с `N` столбцами каждая строка должна содержать ровно `N−1` символ `&`.

![Анализ ошибок структуры строк таблицы](im8.png){ #fig:006 width=80% }

## Использование команды multicolumn

На следующем этапе была исследована команда `multicolumn`, позволяющая объединять несколько столбцов в одну ячейку. Были протестированы варианты объединения двух и трёх столбцов, а также изменение выравнивания объединённых ячеек. Команда показала корректную работу и позволила гибко управлять структурой таблицы.

![Эксперименты с командой multicolumn](im7.png){ #fig:007 width=80% }

# Вывод

В ходе работы были изучены базовые приёмы работы с таблицами в LaTeX. Установлено, что корректное количество элементов в строке является обязательным условием успешной компиляции таблицы. Эксперименты с выравниванием столбцов и командой `multicolumn` показали возможности гибкого управления внешним видом и структурой таблиц, что позволяет эффективно оформлять табличные данные в документах LaTeX.
