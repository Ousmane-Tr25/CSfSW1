# Цель работы

## Основная цель

Изучить основы создания таблиц в LaTeX, освоить способы выравнивания столбцов, разобраться в требованиях к структуре строк таблицы, а также получить практические навыки использования команды `multicolumn` для объединения ячеек.

## Организация проекта

- использование Windows PowerShell;
- переход в каталог с LaTeX-упражнениями;
- создание отдельной папки `chapter-5-tables`;
- подготовка файлов `exercise-5.14.tex` и `exercise-5.14-final.tex`.

## Типы выравнивания

- `l` — по левому краю;
- `c` — по центру;
- `r` — по правому краю;
- комбинации `l-c-r`, `c-c-c`, `r-l-r`.

![Различные выравнивания столбцов](im6.png){ width=70% }

## Анализ некорректных случаев

- недостаточное количество разделителей `&`;
- избыточное количество элементов в строке;
- ошибки компиляции при нарушении структуры.

**Правило:**  
для таблицы с `N` столбцами каждая строка должна содержать ровно `N−1` символ `&`.
