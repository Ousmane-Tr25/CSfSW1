Цель работы

Основная цель

Освоение использования natbib, BibTeX, biblatex и Biber, изучение порядка компиляции и анализ различий между системами управления библиографией.

Работа с natbib и BibTeX

Первый проход pdflatex

  • компилятор сообщает об отсутствующих ссылках,
  • предупреждения об undefined citations,
  • PDF создаётся, но ссылки не определены.

Запуск BibTeX

  • обработка файла .aux,
  • подключение базы references.bib,
  • создание .bbl.

Последующие проходы pdflatex

  • первый — всё ещё предупреждения,
  • второй — ссылки разрешены,
  • третий — чистая компиляция без ошибок.

Результат

  • корректное отображение цитат,
  • список литературы сформирован автоматически.

Установка и использование biblatex + Biber

Установка пакетов

Команды:

  • tlmgr update --self
  • tlmgr install biblatex biber

Последовательность компиляции

  1. pdflatex
  2. biber
  3. pdflatex

Результат

  • корректная обработка библиографии,
  • красивое форматирование,
  • автоматическое создание списка литературы.
